# OpenBot Hermes — Google Workspace integration (personal use)

This repository documents the **personal, single-user** OAuth client used to connect a
private OpenBot/Hermes agent installation on Windows to the owner's own Google account.

- Scope: read/send Gmail, Google Calendar, Google Drive, Google Sheets, Google Docs,
  Google Contacts (read-only).
- The OAuth client is *not* distributed and has no third-party users. The only authorized
  user is `santosmitiel@gmail.com`.
- The client is consumed by a local MCP (Model Context Protocol) server that runs on the
  owner's computer and is called only by the owner's own agents.

## Why this page exists

Google requires a homepage and a privacy-policy URL to move an external OAuth app from
*Testing* to *In production*. Those two documents are here:

- Homepage: this README
- Privacy policy: [PRIVACY.md](PRIVACY.md)
